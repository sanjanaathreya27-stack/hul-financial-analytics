# Financial Performance & Ratio Dashboard: Hindustan Unilever Ltd (HUL)

## Project Overview
This project analyses five years of financial filings (FY21 to FY25) for Hindustan Unilever Ltd (HUL) to identify the underlying drivers of operating margin compression. By modelling key financial ratios and visualizing the data, this analysis provides actionable insights into the company's operational efficiency and working capital management.

## Key Findings
* **Operating Margin Compression:** Identified a reduction in operating margins from 24% to 23%.
* **Primary Drivers:** The analysis revealed that a prolonged working capital cycle and elevated input costs were the primary contributors to the margin compression.

## Tools & Technologies Used
* **Data Extraction & Cleaning:** Microsoft Excel (Power Query)
* **Financial Modelling:** Excel (Operating Margin, ROE, Current Ratio, Cash Conversion Cycle)
* **Data Visualization:** Microsoft Power BI (Interactive Dashboard)

## Methodology
1. **Data Sourcing:** Extracted consolidated financial statements from HUL's annual reports for FY21 through FY25.
2. **Data Transformation:** Cleaned and structured the raw financial data using Excel Power Query to ensure consistency.
3. **Ratio Modelling:** Calculated core performance metrics, specifically focusing on profitability and liquidity ratios.
4. **Dashboard Creation:** Connected the structured Excel models to Power BI to build an interactive dashboard, enabling dynamic exploration of the financial trends.

The dashboard successfully isolates the impact of supply chain costs and working capital delays on overall profitability, demonstrating a practical application of financial analytics in corporate performance evaluation.
